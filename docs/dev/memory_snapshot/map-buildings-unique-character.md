On 2026-11-06 the owner said: "I don't want the buildings to all look the same with a different sign. That is not what the Mario game does. If we need to design smaller buildings or be strategic about making building parts that can be combined in ways that retain the unique character of every venue that's fine."

This answered my suggestion (Q88 c, for a smooth DMG map) to build the buildings from shared parts with a unique sign each.

**Why:** in Super Mario Land 2 every landmark looks different. Those landmarks are small, and they share pieces cleverly, but they aren't clones.

**How to apply:**
- Any DMG map tile-budget art brief must keep each venue recognisably its own: shape, roof and character.
- Tools allowed: smaller buildings, and parts that combine differently per venue.
- Never use one building template with only the sign swapped.
- Proposals go to the owner first.

UPDATE 2026-11-06 (owner, Q91): the town is a map venue like the others: "They were supposed to make the town like all the other venue locations from the same perspective, etc." So the town is drawn as a building group in the same view, scale and style as the other venues on the map, not as a framed scene in the old scene's place. Every map piece follows the other venues' perspective.
