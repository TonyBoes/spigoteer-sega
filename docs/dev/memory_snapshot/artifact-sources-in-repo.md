Owner, 2026-10-21: "I want the artifacts that we've made to be restorable if something happens to our sessions."
Sources live on main in tools/artifacts/ (pocket_player, open_questions, review_board, README.md with URLs + republish steps); the atlas is regenerated by `make atlas` from tools/gfx_atlas/.

**Why:** scratchpad copies die with the session.
**How to apply:** whenever a page is republished from scratchpad, copy the changed html/media into tools/artifacts/ and commit (Opus trailer). New artifact → add a README row with its URL. ROM packs (make_roms.py) and atlas output stay uncommitted.
