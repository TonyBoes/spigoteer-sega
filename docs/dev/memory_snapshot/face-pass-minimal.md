When the owner asks for face work on patrons ("do the same with...", "work on X's head", "head format I've been indicating"), the brief must say: change only face pixels (eyes, mouth, nose, chin); keep hat/cap/hair/body pixel-identical unless he names that part; prove it with a changed-cells check.

**Why:** 2026-10-29 the Lodge pass turned SMITH into "a fat little boy with a paper boat hat" and ROD into "a postal worker"; owner: "I just wanted you to do a little face work, but the agent seems like it wanted to do its own thing." Earlier the batch-2 pass "lost some character" (RAVEN, ROADY, HARLEY, RONIN, LUNA); a template ear on mid-colour hair read as a third eye. The Igloo brief ("only the face changes; parkas identical") worked.

**How to apply:** quote the owner's exact words, but translate "head revision" into "face only, keep identity marks"; ask for a changed-cells table; review the sheet for lost character before showing him. See [[think-before-relaying]], [[art-another-pass-default]].
