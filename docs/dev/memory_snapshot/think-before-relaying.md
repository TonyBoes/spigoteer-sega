On 2026-10-18 the owner asked for the map's venues to be rotated "one position clockwise". I passed his words on with a vague "arrange them in a ring". The agent moved only the left side, so the top was crowded and the bottom-left was empty.

The owner said: "Can you take a long look at it and think about what needs to change logically before you pass it off to the agent?"

This was the second misread of this kind. The first was the boss indicator, where I briefed "left-hand row" when he meant icons above-right plus drinks in the hand.

**Why:** a vague brief costs a whole agent round and the owner's review time.
**How to apply:** before relaying a layout or design instruction, write out its concrete result yourself (a before/after table, an exact mapping, the counts per side) and check it against the current picture. Give the agent that table, not a paraphrase. Ask the agent to restate the plan in its notes and check its output against it.
