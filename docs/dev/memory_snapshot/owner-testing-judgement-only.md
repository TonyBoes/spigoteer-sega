When giving the owner things to test, list only what needs their judgement: how art looks, how music sounds, how play feels, pacing. Mechanics (menus reach the right screens, lives carry, scores save, extra life at 20,000, loop banner) are ours to verify with tests and emulator runs before handing over. Said on 2026-10-11: "A lot of these things you gave me to test are things you can test and don't require judgement calls."

**Why:** the owner's testing time is limited and should go to taste decisions.
**How to apply:** before sending a test list, check each item: if a test or a scripted gbtest run can confirm it, do that and report the result instead. Related: [[art-in-house]].
