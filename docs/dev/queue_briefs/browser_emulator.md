HOST CONSTRAINTS (artifact page CSP; these are hard limits):
- External scripts only from cdnjs.cloudflare.com, cdn.jsdelivr.net/npm/, unpkg.com, pinned to exact versions. Stylesheets only from fonts.googleapis.com.
- Every fetch/XHR/WebSocket to an OUTSIDE host is blocked, including a library's own runtime fetches. Same-origin relative files published with the page (supporting files) are fine to reference with <script src>, and probably with fetch(); prefer <script src="rom.js"> setting a global base64 string, which is safest.
- Assume Web Workers created from blob: URLs and WebAssembly may be blocked. Use a pure-JavaScript emulator core running on the main thread.
- Dialogs (alert/confirm/prompt) don't work; downloads don't work. localStorage works but may throw: wrap every access in try/catch.
- Page size under 16 MB; the ROM is 512 KB.

EMULATOR
- Use WasmBoy 0.7.1's pure-TypeScript core: https://cdn.jsdelivr.net/npm/wasmboy@0.7.1/dist/core/getWasmBoyTsCore.iife.js (or .umd.js). This avoids wasm and workers.

PAGE
- A 160x144 canvas scaled to an integer factor, pixelated.
- On-screen controls for touch (phone held upright): a D-pad, A, B, START, SELECT, with multi-touch (e.g. right+A at once). Pointer events, not just click.
- Keyboard: arrows, Z/X for B/A (or X/Z: say which), Enter, Shift.
- Audio via WebAudio, started on the first tap (browser autoplay rules), with a mute toggle.
- Run at 59.73 fps from a requestAnimationFrame clock (catch up or skip consistently on 120 Hz screens).
- A model switch: Game Boy Color / original DMG (if the core can force DMG mode for a dual-mode ROM; if not, say so).
- Reset button. Save RAM (cartridge battery) kept in localStorage per ROM build, if the core exposes cartridge RAM.
- A visible "ROM: <build/commit>" line, so the owner knows which build it is.
- A short note: "Quick-test emulator. Timing and graphics may differ from real hardware; SameBoy and a real Game Boy are the reference."
- Theme-aware page chrome (light/dark tokens on :root; prefers-color-scheme with the [data-theme] overrides; body sets its background), responsive to ~400 px wide with 16 px gutters.
- A <title> such as "Spigoteer Pocket Player".
