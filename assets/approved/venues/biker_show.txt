; The Chrome Cow (theme biker, patron group punks): owner-approved 2026-10-11 (art round 5); imported from the punk_* proposal files
; punk show (PROPOSAL round 4): the band. 6 frames 16x24 = 3 performers x 2 frames, in this order:
;   0: guitarist A (pick up)
;   1: guitarist B (strum)
;   2: singer A (head up)
;   3: singer B (nod, at the mic)
;   4: drummer A (left stick up, right on the drum)
;   5: drummer B (cymbal crash, right stick up)
; dancer slots (render.c dancer_x 24, 72, 120): guitarist, singer, drummer; each shows its frame A on even beats and B
; on odd ones (DANCER_BEAT 12): pick up / strum, head up / nod, stick up / cymbal crash.
; Budget: the 6 frames dedupe to 16 unique 8x16 OAM tiles = 32 OBJ tiles, the same 32 as a 4-frame
;   performer (OBJ_DANCER 96..127): each pose changes only the 8x16 quarters it must (guitarist: top-left; singer:
;   top-right, the head; drummer: both tops), the bottoms never change. Quarter ids per frame (TL TR BL BR):
;   0:[0, 1, 2, 3]  1:[4, 1, 2, 3]  2:[5, 6, 7, 8]  3:[5, 9, 7, 8]  4:[10, 11, 12, 13]  5:[14, 15, 12, 13]
; Engine (built): tools/gen_art.py show_tiles dedupes the 6 frames into these quarters (2 OBJ tiles each) and writes
;   the table (venue.show_tile, OBJ tile offsets = 2 x the ids above); src/render.c draw_dancers gives performer k the
;   row 2k + (beat & 1). The palette stays one OBJ palette (biker_show_pal.json).
; palette: - skin / drum head / cymbal (DMG white), + acid green hair, guitar, sticks, logo (DMG light grey), # black
